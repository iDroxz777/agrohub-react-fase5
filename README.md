# AgroHub (React)

Plataforma que conecta pequenos produtores rurais a ONGs, pra destinar excedentes e alimentos fora do padrão comercial em vez de jogar fora. Projeto em grupo da FIAP (2026, Grupo 44), alinhado à ODS 2, Fome Zero.

**No ar:** https://erickito30.github.io/agrohub-react-fase5/
**Repositório original:** [Erickito30/agrohub-react-fase5](https://github.com/Erickito30/agrohub-react-fase5)

## Minha parte

- Migrei as páginas da versão em HTML pra React: Home, Cadastro, Produtor, ONG e Contato, mantendo o design original.
- Revisei as páginas e corrigi a navegação entre rotas e o sistema de notificações.
- Configurei o deploy no GitHub Pages.

O resto do grupo fez o setup do React com rotas e layout, o painel da ONG e o sistema de notificações: quando o produtor cadastra um excedente, aparece um aviso no sino e o item entra na lista da ONG pra agendar a coleta.

## Stack

React · React Router · Context API · Vite · GitHub Pages

## Rodando local

```bash
cd agrohub-react
npm install
npm run dev
```
